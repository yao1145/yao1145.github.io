# Robots 滑行

四台机器人停在 16 × 16 棋盘上。选一台、选一个方向，它会一直滑，直到撞上外墙、撞上内墙，或者被另一台机器人挡住，停在它前面一格。四台同时停在自己的目标格上，本关完成。

从仓库根目录启动静态服务后访问 `/robots/`，也可以直接打开 `index.html` 离线游玩。页面使用原生 HTML、CSS 和 JavaScript，没有外部依赖，样式与脚本都在本目录内，复制目录即可独立运行。

## 规则与操作

- 机器人不能主动停下，也不能被推动。滑行方向上紧挨着另一台机器人时，这一步不合法，不计入步数。
- 内墙在格子边上，两侧一致：一条边对两边的格子都算墙。
- 每台机器人有自己的颜色和符号，棋盘上有同色同符号的目标格。四台**同时**停在各自的目标上才算完成。
- 已经到位的机器人仍然可以移动，可以滑开也可以滑回来，它不会被锁住。
- 点机器人选中它，再点方向按钮；键盘按 1–4 选机器人，方向键或 WASD 滑行；手机上也可以直接在棋盘上朝一个方向划动。
- Z 撤销，R 重开。撤销逐步回退，重开回到本关初始局面，两者都不清除已经得到的星星。
- 动画默认跟随减少动态效果偏好，玩家手动选择的速度在本次及后续打开时优先。棋盘使用 `touch-action: pinch-zoom`，单指划动不会被页面滚动截走，捏合缩放仍然可用。

## 十二关与记录

十二关都使用随机分散的 L 形短墙、边缘挡板与中央 2 × 2 障碍，前四关 48 段、中四关 56 段、后四关 64 段格边内墙。四个目标均位于内部，至少一个目标没有相邻固定墙，必须借助其他机器人挡停；后六关至少有两个这样的目标。各关可证明的总步数下界为 10–15 步，保存的合法解为 13–60 步，证书长度不用于宣称最优难度。

每关首次通关点亮一颗星，并记录该关用到的最少步数。记录保存在 `yaozi.robots.progress.v1`，关卡版本为 `scatter-v2`。升级保留已点亮的星星，并归档旧步数纪录，新关卡重新计纪录。动画偏好保存在 `yaozi.robots.motion`，语言与主题沿用主页的 `yaozi.home.language` 与 `yaozi.home.theme`。存储不可用时仍可游玩，星星在本次打开期间保留，页面会给出提示。

每日一局以北京时间日期为种子，当天所有人拿到同一道题，题目档位也由日期决定。随机挑战每次更换种子，并在十二个档位之间轮换。两者都不点亮星星，也不写入固定关记录。

## 有解构造与下界

随机摆放的机器人加随机目标常常无解，所以题目从一条真实走过的路线反向确定。

生成器先在一张合法初始局面上随机滑行：每一步都用引擎判定合法性（外墙、内墙、其他机器人），推进一步就记录一步，走完把终局里四台机器人所在的位置取为各自的目标。目标因此天然相容，而整条路线就是可回放的证书。随后筛掉退化局面：机器人已经站在自己的目标上、整局从未移动、或者四台各滑一次就能结束。证书会由 `replay` 逐步核对，落点、挡停原因和最终四台归位都要成立。

难度用下界衡量。把其他机器人拿掉、并且允许机器人滑到任意一格停下，这个松弛模型里每台机器人的最少滑动次数是它在原问题里所需步数的下界：原问题的每一步在松弛模型里都合法。四台相加就是总步数的下界，用 252 个可进入格上的广度优先搜索就能算出。只把其他机器人拿掉、仍要求滑到挡板前才停的距离不能当界——挡板有时正好把机器人停在你想要的位置，去掉挡板反而更难。

页面上给出证书步数与下界：证书是一条 N 步的合法解，下界说明任何解法都至少需要 M 步。N 是否最小，本游戏不计算，也不作声明。

完整状态是四台有标号机器人的位置四元组。每台机器人占一格且互不重叠，中央四格不可进入，因此状态数不超过 252 × 251 × 250 × 249 = 3 937 437 000，约 3.94 × 10⁹。在这张配置图上做广度优先搜索可以得到最少滑动次数，这个规模不适合逐点展开，本作也不要求最少步数，因此实现选择构造与回放。

## 限额与取消

生成是有界且可中断的：`generateSteps` 每次尝试后让出一次控制权，页面分批推进并在批次之间让出主线程，切换关卡、点“取消生成”或刷新都会让过期结果作废。每次尝试都有独立的种子分支，最多尝试 600 次。新布局不放宽难度阈值；限额内未找到题目时，从满足该档位下界、墙数和借位条件的已核验题库中选择，并作旋转、镜像及机器人与目标成对换色。固定关直接读取已核验题目。

## 文件与接口

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构、可折叠玩法与数学说明、中英文标记 |
| `style.css` | 页面样式，含明暗主题与本目录内的棋盘样式 |
| `engine.js` | UMD 纯函数引擎：滑行、回放、下界、墙体布局、生成器 |
| `game.js` | 界面、键盘与触控、记录、每日与随机、中英文字典 |
| `verify.cjs` | 独立验证脚本 |
| `README.md` | 本文件 |

`engine.js` 在浏览器中是 `RobotsEngine`，在 Node 中可通过 `require` 读取。状态为 `{w, h, robots, targets, walls}`：`robots` 与 `targets` 各是四个 `[x, y]`，`walls` 是格边编码数组，一条边只有一个编码，两侧格子读到同一个值。

| 接口 | 用途 |
| --- | --- |
| `slide(state, robot, dir)` | 返回这次滑行的起点、终点、格数与被什么挡住；滑不动时返回 `null` |
| `applyMove(state, move)` | 返回新状态；不合法时 `ok: false`，原状态不变 |
| `legalMoves(state)` | 列出当前所有合法滑行 |
| `isWon(state)` / `onTargetCount(state)` | 四台是否同时归位／已归位台数 |
| `relaxedDistance` / `relaxedLowerBound` | 松弛模型下的单台距离与总下界 |
| `replay(state, solution)` | 回放证书并检查最终四台归位 |
| `wallsOk(state)` | 检查可进入格连通且没有死格（每个可进入格至少两条开放边） |
| `buildWallLayout(kind, r)` | 由种子随机流生成指定类型的墙体布局 |
| `generateSteps(seed, options)` | 可分片的确定性构造迭代器 |
| `generate(seed, options)` / `generateLevel(index)` | 同步构造并返回题目与证书 |
| `shanghaiDateString(date)` / `dailyTier(date)` | 以 UTC+8 得到每日日期与每日档位 |
| `LEVELS` / `LAYOUT_LABELS` / `FALLBACK_PUZZLE` | 十二关档位、布局名称、兜底局面 |

浏览器测试接口 `window.RobotsGame`：

| 接口 | 用途 |
| --- | --- |
| `snapshot()` | 深拷贝的 `puzzle`、`state`、`moves`、`won`、`levelIndex`（非固定关时为 `null`）、`mode`、`stars`，并附带 `certificate`、`certificateLength`、`lowerBound`、`sequence`、`selected`、`history`、`seed`、`dailyDate`、`animating`、`generating`、`storageAvailable` |
| `loadLevel(0..11)` | 载入固定关 |
| `ready()` | 当前没有待完成的动画或生成任务 |
| `playSolution()` | 依次点击式回放本题证书，返回是否已经归位 |
| `play(robot, dir)` / `select(index)` | 等价于点机器人加方向按钮／选中机器人 |
| `cancelGeneration()` | 取消正在进行的每日或随机生成 |

稳定 DOM 接口：`#board`、`#undo`、`#restart`、`#daily`、`#random`、`#next`、`#language-toggle`、`#theme`、`[data-level="0".."11"]`。另提供 `#dir-up`、`#dir-right`、`#dir-down`、`#dir-left`、`#robot-0`..`#robot-3`、`[data-robot]`、`#motion`、`#cancel`、`#solution-note`。

中英文文案集中在 `game.js` 顶部的 `DICT`，页面静态文字用 `data-t` 标记对应键。

## 验证

从仓库根目录运行：

```sh
node robots/verify.cjs
```

脚本用自己实现的滑行、挡板、连通性与松弛下界交叉核对引擎，覆盖：墙与碰撞（不推机器人、不越界、不穿墙、停在前一格）、封锁方向不算一步、机器人站在自己目标上仍可移动、4 × 4 小棋盘上穷举配置图得到的真实最少步数与松弛下界的关系、十二关与批量随机／每日题目的独立回放、题目不重叠（机器人之间、目标之间）、墙体两侧一致、种子重现、北京时间跨日，以及限额分支与兜底局面。任一项失败时脚本以非零状态退出并打印失败项。

## 说明

页面基础样式按本目录独立维护，不引用其他游戏目录的文件。棋盘使用 CSS 容器查询单位设置棋子字号，不支持容器查询单位的浏览器回退到固定字号。
