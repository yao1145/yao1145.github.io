# Yaozi 的小游戏

[中文](#中文) · [English](#english)

## 中文

十二款浏览器小游戏，打开网页就能玩，支持电脑和手机。

[进入网站](https://yao1145.github.io/)

| 游戏 | 玩法 |
| --- | --- |
| [PKUfighter](https://yao1145.github.io/pkufighter/) | 驾驶北大校徽躲避弹幕、迎战高校 Boss，用效果卡搭配战斗路线。 |
| [十步万度](https://yao1145.github.io/clocks/) | 拨动 25 枚指针，让旋转接力。在 1–12 步挑战中争取满分，收集十二颗星。 |
| [Cube](https://yao1145.github.io/cube/) | 在 4×4 棋盘上滚动立方体，与落点交换颜色，用最少步数让六面全蓝。 |
| [Sixteen](https://yao1145.github.io/sixteen/) | 循环滑动整行整列、旋转 2×2 方格，用最少步数把 1–16 复原。 |
| [王冠巡游](https://yao1145.github.io/knight/) | 让王冠按国际象棋骑士的走法移动，每格恰好经过一次，挑战 5×5 到 8×8 的棋盘。 |
| [Tronix · 解结](https://yao1145.github.io/tronix/) | 拖动节点，解开全部交叉连线，挑战逐渐复杂的平面图。 |
| [顶点着色](https://yao1145.github.io/coloring/) | 给相连的顶点填上不同颜色，用最少颜色完成整张图。 |
| [Swap 全清](https://yao1145.github.io/swap/) | 交换相邻方块，消除同色邻块，主动下落，清空全部方块。 |
| [Flip](https://yao1145.github.io/flip/) | 翻转局部方格，用最少点击点亮全盘。 |
| [Pegs · 孔明棋](https://yao1145.github.io/pegs/) | 在多种棋盘上跳吃棋子，最终只留一子。 |
| [Robots · 四机归位](https://yao1145.github.io/robots/) | 机器人遇障碍才停，让四台同时停在各自目标上。 |
| [HEX XII](https://yao1145.github.io/hex/) | 执红棋连接上下两边，挑战三档 AI、十二关，或自由选择 7×7 到 13×13 棋盘。 |

主页与 PKUfighter 以外的游戏可切换中英文，并沿用同一语言偏好。这些页面也支持明暗主题。成绩和通关记录保存在当前浏览器，各游戏页面有具体操作说明。

## English

Twelve browser games for desktop and mobile. Open the site and pick one to play.

[Visit the site](https://yao1145.github.io/)

| Game | How to play |
| --- | --- |
| [PKUfighter](https://yao1145.github.io/pkufighter/) | Pilot the Peking University emblem, dodge bullets and fight university bosses. Choose effect cards to shape your run. |
| [Clock Relay](https://yao1145.github.io/clocks/) | Set 25 clock hands in motion. Aim for a perfect score in challenges from 1 to 12 moves and collect twelve stars. |
| [Cube](https://yao1145.github.io/cube/) | Roll a cube across a 4×4 board, swapping colors with each landing square. Turn all six faces blue in the fewest moves. |
| [Sixteen](https://yao1145.github.io/sixteen/) | Slide rows and columns cyclically and rotate 2×2 blocks. Put 1–16 back in order in the fewest moves. |
| [Crown Tour](https://yao1145.github.io/knight/) | Move the crown like a chess knight and visit every square exactly once, on boards from 5×5 to 8×8. |
| [Tronix · Untangle](https://yao1145.github.io/tronix/) | Drag nodes to uncross every line in increasingly intricate planar graphs. |
| [Vertex Coloring](https://yao1145.github.io/coloring/) | Give connected vertices different colors and solve each graph with the minimum number of colors. |
| [Swap · Clear All](https://yao1145.github.io/swap/) | Swap adjacent tiles, clear matching neighbors, and choose when to drop. Clear every tile to win. |
| [Flip](https://yao1145.github.io/flip/) | Flip local patterns and light every tile in the fewest clicks. |
| [Pegs · Solitaire](https://yao1145.github.io/pegs/) | Jump and remove pegs on different boards, leaving just one. |
| [Robots · Chain](https://yao1145.github.io/robots/) | Slide four robots and park them on all four matching targets at once. |
| [HEX XII](https://yao1145.github.io/hex/) | Connect the top and bottom with red stones. Play twelve levels against three AI difficulties, or choose any board size from 7×7 to 13×13. |

The homepage and all games except PKUfighter support Chinese and English, sharing your language preference. These pages also have light and dark themes. Scores and completed levels are saved in your browser. Each game has its own controls and instructions.
