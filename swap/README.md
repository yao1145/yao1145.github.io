# Swap 全清

交换相邻方块，同色相邻即消除。消除后留下空洞，玩家主动使用下落整理棋盘。清空全部方块才通关，游玩过程中没有补块、道具或时间限制。

从仓库根目录启动静态服务后访问 `/swap/`，也可直接打开 `index.html`。页面使用原生 HTML、CSS 和 JavaScript，基础界面样式引用 `../tronix/style.css`，需要保留相对目录结构。

## 规则与操作

- 点击两块上下或左右相邻的方块交换，允许不产生消除的预备交换；空格不能参与交换。
- 同色方块横向或纵向相邻即消除，所有符合条件的方块同时结算。三个或更多方块组成的同色区域也会全部消除。
- 交换不会自动下落。点击“下落”后，所有列向下压实，结算消除，再继续下落，直到棋盘稳定。整次连锁计一次下落。
- 某种颜色只剩一块时已经无法清盘，界面提示撤销或重开。没有孤块不保证当前局面仍然有解。
- 方向键移动焦点，Enter 或空格选块；G 下落，Z 撤销，R 重开。
- 撤销恢复整次操作，包含完整下落连锁。重开、撤销和切关保留已获得的星星。

颜色配合圆形、三角、菱形和十字标记，便于辨认。动画默认跟随减少动态效果偏好，玩家手动选择的速度在本次及后续打开时优先。

## 十二关与记录

固定关卡从 4×4 到 7×9，初始方块从 10 块增加到 52 块。保存的清盘路线逐步加入预备交换、下落消除和两波连锁。第 5–12 关筛除能被“优先消除最多方块”的确定性贪心策略直接清空的布局；这项筛选不等同于人类难度评定。

每关首次全清点亮一颗星。成绩分别记录交换与下落次数，最佳成绩优先比较总操作次数，总数相同时比较下落次数。保存路线是有解见证，页面不把其长度标为最少步数。

记录保存在 `yaozi.swap.progress.v1`，动画偏好保存在 `yaozi.swap.motion`，主题沿用 `yaozi.home.theme`。存储不可用时仍可游玩，收藏在当前页面内保留。

## 有解构造

`engine.js` 是 UMD 纯函数模块，浏览器中为 `SwapEngine`，Node 中可通过 `require` 读取。状态采用 `{w,h,cells}`，空格为 `-1`，颜色从 `0` 编号。

生成器从可以清空的小局面反向构造：反向交换并加入成对方块，验证正向操作恰好恢复上一步；在紧实局面上构造下落消除片段，再打散各列中的高度；最后加入合法预备交换。每一步都保留回到已知可解局面的动作，形成完整清盘路线。

生成结束后回放整条路线，要求所有交换与下落合法，最终没有任何方块。生成中的反向加入只用于制作关卡；玩家接口只接受 `swap` 和 `drop`，正向操作不会增加方块。

每日按北京时间日期确定种子。随机挑战在困难和专家规模间交替，改变布局、颜色和清盘过程。两种模式都运行同一确定性构造与见证校验：HTTP 环境优先使用 Worker，Worker 不可用时逐步构造并让出主线程。取消、重开和切关会使过期结果失效。

主要接口：

| 接口 | 用途 |
| --- | --- |
| `apply(state, action)` | 返回操作结果、最终状态及交换/消除/下落动画帧；不修改输入 |
| `matches(state)` | 返回所有同色相邻区域中的格子 |
| `analyze(state)` | 返回剩余数量、各色数量、孤块及状态 |
| `replay(state, solution)` | 回放动作并检查全清 |
| `generateSteps(seed, difficulty)` | 可分片的确定性构造迭代器 |
| `generate(seed, difficulty)` | 同步构造并返回棋盘与清盘见证 |
| `shanghaiDateString(date)` | 以 UTC+8 确定每日日期 |

## 验证与关卡文件

```sh
node swap/verify.cjs
```

验证脚本穷举 2×2 小棋盘的合法操作，用独立的连通区域搜索和列压实实现交叉核对规则，并独立回放十二关与 160 张随机关卡。检查范围包括同时消除、预备交换、空洞保留、下落连锁、禁止补块、死局提示条件、种子重现和北京时间跨日。

`levels.js` 保存十二关及清盘见证。只有显式运行 `node swap/build-levels.cjs` 才会重新生成并覆盖该文件；验证脚本只读。

`SwapGame.snapshot()` 返回状态副本，`loadLevel(index)` 加载 0–11 号关卡，`ready()` 表示没有待完成的动画或生成。DOM 接口包括 `#cell-N`、`[data-level]`、`#drop`、`#undo`、`#restart`、`#motion`、`#daily`、`#random` 和 `#cancel`。
