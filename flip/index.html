玩法与全亮规则

点击方格，翻转一片

每个格子里都有一张 3×3 的小图。中间那点代表这一格本身，其余位置是它的邻格。

按下一格，会翻转小图上标出的所有格子，包括它自己。

小图逐格不同：有的格子只影响上下左右，有的还带上斜角，范围大小也不一样。熄着按下去就亮，亮着按下去就熄。

全部方格亮起即通关。斜向是否受影响，只按小图判断，不按格子的位置猜。

预算、撤销与重开

每关的最优步数由程序精确算出，作为本次的预算。必须在预算内点亮全部方格；预算耗尽而仍有暗格，本局失败。

预算耗尽而棋盘还没全亮，本局失败。撤销最近几步仍然有效，重开回到本题初始局面，星星不会被清除。

最佳成绩记录本关用掉的按键次数，撤销与重开都不会清除它。

操作：点击方格，或用方向键移动焦点后按 Enter / 空格。Z 撤销，R 重开，H 提示还需要几步。提示只报数量，不代你按。

数学与算法：模 2 线性方程组

每个局面都是一个模 2 方程组

把“这一格是否亮着”记作 0 或 1。按下某格，等于给一组格子各加上 1。同一个格子被按两次就抵消回原状，按下顺序也不影响结果。

于是一次游戏真正决定的东西只有按了哪些格，每格按 0 次或 1 次。设 A 记录“按下第 j 格会动到哪些格”，x 记录“按了哪些格”，b 记录“哪些格还需要被翻转”。全亮等价于求解 A x = b，加减都在模 2 下进行，也就是异或。

A 的第 j 列由第 j 格的小图决定。3×3 的局部作用限定了这一列中哪些位置可以为 1。

高斯消元给特解，零空间给全部解

对增广矩阵做模 2 高斯消元，可以判断方程是否有解，给出一个特解 x0，并得到零空间维数 d。全部解是 x0 + ker A，一共 2 的 d 次方个。A 奇异时同一盘棋确有多个解，界面上的解数量就来自这里。

高斯消元给出的解不一定最短。要最少步数，就得枚举零空间的全部向量，取按格数最少的一个，这个最小重量就是本关预算。

经典 5×5 十字模式的矩阵秩为 23，零空间维数为 2。因此 2²⁵ 种亮暗布局中，有 2²³ 种可解，占四分之一；每个可解布局有四个奇偶点击方案。随机邻域模式的秩随作用图变化，应逐题计算。

固定关的零空间维数限制在 4 以内，最多枚举 16 个向量，实时计算可以精确完成。

生成器反过来用这套代数：先随机生成每格的作用范围，再挑一组按键方案，用 b = A x 反推初始棋盘。题目在出题时已经有解，随后枚举零空间求出精确最优值，并回放这条最优路线作为证书。
