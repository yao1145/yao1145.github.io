# Pegs · 孔明棋

选择棋子，跳过相邻棋子落入空孔，移除被跳过的棋子。最后只留一子；标有星形终点的关卡，还需在该孔结束。方格棋盘允许横纵跳跃，三角棋盘允许沿三条格线的六个方向跳跃。

十二关使用六种棋盘，初始棋子数依次为 12、20、28、13、32、36、32、40、34、36、32、44。第 11 关为英国十字 33 孔的 32 子中心单缺题，第 12 关为 Wiegleb 45 孔的 44 子中心单缺题，两关都要求最后回到中心。另有按北京时间生成的每日一题和随机挑战。支持中英文、明暗主题、撤销、重开和本地星星记录。可以通过 HTTP 访问 `/pegs/`，或直接打开本目录 `index.html`。

页面的“数学与算法”说明单次跳跃计数、分层有向无环图、模二位置类、宝塔函数和逆向构造。固定关保存经过逐跳回放的解证书；每日与随机题用反向扩展构造。英国十字与 Wiegleb 的中心题证书依据 George Bell 的[英国十字解图](https://www.gibell.net/pegsolitaire/English/index.html)与 [Wiegleb 研究](https://www.gibell.net/pegsolitaire/Wiegleb/index.html)核验。其他部分占子题按实际初始子数标注。

从仓库根目录运行 `node pegs/verify.cjs` 验证几何规则与题目证书。

`PegsEngine` 为无依赖 UMD 纯函数模块。`PegsGame.snapshot()` 返回局面副本，`loadLevel(0..11)` 切关，`ready()` 表示生成已完成。浏览器检查可依次点击证书三元组的起孔 `#hole-a` 与终孔 `#hole-c`；每跳只计一次。存档键为 `yaozi.pegs.progress.v1`，关卡版本为 `dense-v2`。升级保留旧星星，把旧步数纪录归档，新关卡重新计纪录。语言与主题沿用主页偏好。
