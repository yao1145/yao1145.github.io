# 32 个 Loopover 局面的混合规则验证

**32 / 32 全部通过：每个局面都有不超过 16 步的合法解。** 下表记录找到的解长度，验证结论是最短步数 ≤16。

规则：4×4；整行或整列循环移动一格；任一不跨边界的相邻 2×2 区域旋转 90°。每个动作计一步。

32 组全部独立搜索；解序列再由不调用游戏引擎移动函数的独立数组代码重放。JSON 保存输入、动作 ID、文字动作、每步完整棋盘与节点数。

## 对称性核对

仅滑动规则的 128 个环面方格对称变换，确实把所给数据分成以 1、2、3 号为代表的 8、16、8 三类。在这 128 种变换中，保持全部 34 个混合操作合法的只有 8 个：非零环面平移可能把相邻 2×2 旋转区搬到跨边界位置。因此本验证对所有 32 组逐个求解，不依赖三代表能覆盖混合规则。

## 复现

在仓库根目录运行：

```sh
node sixteen/verify-loopover-32.cjs
node sixteen/verify-loopover-32.cjs --replay
```

第一条重新搜索并生成报告；第二条只用独立代码核对已有证书。输入 SHA-256：`206a292e1918bdc0fdf6c06a724b35e405327a39709b66489c9e79e83f44c3cb`。

若接受“仅滑动的直径为 18，且恰有这 32 个 18 步局面”的穷举结论，则其余局面原本最多 17 步，而以上 32 个在混合规则下至多 16 步；结合另已证明需要 17 步的混合局面，可以推出混合规则的全局最大最短步数恰好为 17。该全局推论以原 Loopover 穷举结论及名单完整性为前提。
